How it works

Every certificate issued by Coding Club carries a unique cryptographic ID. When you enter an ID, our system checks it against the Supabase-backed registry in real time.

Security

Each certificate is SHA-256 signed. The verification portal is read-only — no private data is exposed beyond what is printed on the certificate itself.

Need help?

If a valid certificate shows as invalid, contact us at certificates@codingclub.dev with the certificate ID.
